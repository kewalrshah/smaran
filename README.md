# Smaran website

The info, support and privacy pages for Smaran, an iPhone app for reading and reciting the Bhagavad Gita, Stotras, Vedic mantras and Upanishads.

Live at https://kewalrshah.github.io/smaran/

- Support: https://kewalrshah.github.io/smaran/support.html
- Privacy policy: https://kewalrshah.github.io/smaran/privacy.html

When the app is on the App Store, replace the "Coming soon" button in `index.html` (it is marked with a comment) with the real App Store link.
